# Shosholoza Website

Official website for the Shosholoza program.

## Project Overview

This is a modern, responsive website for Shosholoza, designed to provide information about the program and facilitate applications.

## Features

- Clean, professional design
- Fully responsive layout
- Easy-to-navigate structure
- Contact and application forms

## Project Structure

```
shosholoza-website/
├── index.html          # Home page
├── about.html          # About Shosholoza
├── contact.html        # Contact information
├── css/
│   └── styles.css     # Main stylesheet
├── js/
│   └── main.js        # JavaScript functionality
├── images/            # Image assets
└── README.md          # This file
```

## Getting Started

### Local Development

1. Open `index.html` in your web browser
2. Or use a local server:
   ```bash
   python -m http.server 8000
   # Then visit http://localhost:8000
   ```

### Deployment

This is a static website and can be deployed to:
- GitHub Pages
- Netlify
- Vercel
- Firebase Hosting
- Any static hosting service

## Technology Stack

- HTML5
- CSS3
- Vanilla JavaScript (no dependencies)
- Mobile-first responsive design
